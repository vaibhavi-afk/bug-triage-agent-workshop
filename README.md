# IT Bug Triage Co-Build

Follow-along guide for building a multi-agent IT bug triage system in Lyzr Agent Studio.

- **Guide:** open `index.html`, or the GitHub Pages link for this repo
- **Files:** the `files/` folder has everything you upload to Studio
  - `known_issues.csv` and `component_owners.csv` become semantic models
  - `release_notes.docx`, `runbooks.docx` and `severity_rubric.docx` go into knowledge bases
  - `bug-triage-files.zip` has all five

All names in the data are fictional and emails use example.com.
